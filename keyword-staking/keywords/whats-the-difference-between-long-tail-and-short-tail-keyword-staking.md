# What’s the difference between long-tail and short-tail keyword staking?

&#x20;Short-tail keywords (like “best”) trigger ads when a user starts their search with that word, for example,&#x20;“best cookies.” Long-tail keywords (like “the best”) only trigger ads if a user searches that exact phrase&#x20;with nothing after it. So if someone searches “the best bicycle brand,” the ad will only show if that full&#x20;phrase was staked. If not, the ad staked on the first word (“the”) would show instead.
