# Can I run Presearch node besides Flux node ?

**Why?**

Flux node can actually host a Presearch node as a service. As a result to that there is no support for hosting together Flux and Presearch node on same public IPv4 address / same host.

> Note: If you attempt to run both simultaneously, your node logs may become cluttered with duplicate node statements, leading to potential issues.
