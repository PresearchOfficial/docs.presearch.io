# Will there be IPv6 support for Presearch nodes ?

Why ? The use of IPv4 is intended as a measure to ensure decentralization. Since IPv4 addresses are limited in supply, they are less accessible compared to IPv6 addresses, which can often be obtained for free. This helps prevent scenarios where a single operator could exploit the availability of free IPv6 addresses to run an excessive number of nodes from a single hosting machine. This policy aligns with Presearch's mission to maintain a truly decentralized network.
