# ⚙️ Presearch UI/UX updates

Hello Presearchers,

Some weeks ago we told you we’d be rolling out waves of UI/UX updates.\
The first wave of updates has been shipped live!\
Head over to presearch.com on desktop or mobile and see the difference and give it a search.\
Like before, tell us your first thoughts, suggestions, or any bugs you find in this post.\
Here is a summary of the updates from the first wave:\
UI Streamlining:\
✅ removed social and crypto icons from the homepage (socials still in hamburger)\
✅ removed Learn/Login/Sign Up buttons from the homepage\
✅ removed OnChain Showcase (search page)\
✅ removed “Results from decentralized nodes in the…” (search page)\
✅ changed from “Presearch” name logo to “P\_” symbol logo\
✅ search bar:\
✅ moved up (more space and clearer distinction as a search bar from the background)\
✅ rounded edges\
✅ magnifying glass on the left\
✅ More color and space consistency\
Updates to presearch.io:\
✅ updates related to uses of PRE\
✅ updates related to web3
