# How to Set Presearch as Your Default Search Engine on Safari | Alternative Search Engine Tutorial

1. On your Mac's desktop, start by opening Safari.
2. Next, go to the top left corner of the screen and click Safari in the menu bar.
3. Then select preferences.
4. In the preferences window on the general tab, find the home page field, type [presearch.com](https://presearch.com/), and then press enter to save it.
5. Now locate the newly opened windows and select the home page from the drop-down menu. Do the same for the newly opened tabs. Set this to the home page as well.
6. Once this is done, everything will be ready. The next time you open Safari, Presearch will start automatically.
